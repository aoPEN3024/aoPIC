# クラウド写真送信（現場共有）について

## これは何か
撮影した工事写真を、現場ごとの共有先（Supabase）へ送信するための機能です。
設定しない場合は、写真はこの端末の中だけに保存されます（従来どおりの使い方）。

## 使い始めるまで
1. 設定画面で「Supabase Project URL」と「Publishable key」を入力し、「接続先を保存」を押します。
2. 「現場ID」と「参加コード」、この端末の名前を入力し、「現場に参加」を押します。
3. 接続に成功すると、現場名・権限・通信状態・未送信件数が表示されます。

## 写真の送信
- 送信のタイミングは「Wi-Fi接続時だけ送信」「どの回線でも送信」「手動で送信」から選べます。
- 「今すぐ送信」で、未送信の写真を1件ずつ送信します。
- 送信を止めたいときは「一時停止」、続けるときは「再開」を押します。
- 送信に失敗した写真は「失敗分を再送信」でやり直せます。

## すでに撮った写真を送りたいとき
「送信する工事を選ぶ」で工事を選び、「既存の写真を送信対象に追加」を押すと、
その工事の写真が送信対象に加わります。

## この端末だけで使いたいとき
「この端末だけで使う」を押すと、現場との共有を解除します。
送信待ちの写真は送信されません。

## うまくいかないとき
- 「オフラインのため送信できません」：通信環境を確認してください。
- 「Wi-Fi接続時だけ送信」にしている場合、Wi-Fi以外では送信を保留します。
- 「参加できませんでした」：現場IDと参加コードを確認してください。

## 注意
- 撮影・黒板合成・CSV・ZIP・台帳などの既存機能はこれまでどおり使えます。
- 接続先を設定しなくても、この端末だけで写真を撮って保存できます。
